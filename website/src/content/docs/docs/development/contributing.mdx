Contributions are welcome. CaberOS is developed end-to-end: features that cross the gateway, harness, syscall, storage, or frontend boundaries are implemented as vertical slices.

## Setup

See [Local development](/docs/development/local-development/) for prerequisites, setup, and running the dev servers.

## Backend checks

```bash
cd backend
uv run pytest -v
uv run ruff check src/ tests/
uv run ruff format --check src/ tests/
```

## Frontend checks

```bash
cd frontend
npm ci
npm run lint
npm run build
npm run test
```

## Desktop build (macOS only)

```bash
cd frontend
npm run desktop:build
```

The build bundles the PyInstaller gateway and the React frontend. Release builds additionally require the Tauri signing secrets configured in GitHub Actions.

## Website build

```bash
cd website
npm install
npm run build
```

## Guidelines

- Implement features end to end when they cross the gateway, harness, syscall, storage, or frontend boundaries.
- Add behavioral tests at the public seam.
- Keep security-sensitive failures generic to API clients.
- Include the relevant verification commands in the pull request.
- Follow existing code style and patterns — check neighboring files before introducing new abstractions.
