CaberOS creates its local data directory the first time the gateway starts. The desktop shell waits for the local health endpoint before showing the dashboard.

## 1. Sign in

The initial operator account is:

```text
username: admin
password: admin
```

The onboarding flow asks you to replace these default credentials inline — do that before continuing. You can change them again later from Settings.

## 2. Follow the onboarding guide

The first-run wizard walks through:

- **Welcome** — what CaberOS is and what stays on this machine.
- **Protect your workspace** — replace the default sign-in credentials.
- **Get your machine ready** — live readiness checks against the local health and dependency probes, including the managed browser and command sandbox; optional runtimes can be installed or skipped.
- **Connect an AI** — add a model-provider key or a local model endpoint and validate the connection.
- **Choose what agents may do** — the default permission posture.
- **Meet your agents** — review the seeded agents.
- **Ready** — you land on the **Today** page, the operator home that surfaces what your agents did and what needs you.

After onboarding, Today offers a short three-step tour of the home surfaces. You can replay it any time from **Settings → General → Guidance → Replay tour**.

## 3. Send a first message

Open the **Caber** agent and ask it to inspect its workspace. A successful run should show:

- the user message;
- model response streaming;
- any thinking or tool activity;
- approval prompts when needed;
- a completed run in the trace view.

## 4. Check health

The dashboard health view reports database, providers, agents, active runs, MCP servers, and channels.

You can also check the gateway directly:

**Desktop app:**

```bash
curl http://127.0.0.1:51718/health
```

**Docker:**

```bash
curl http://localhost:8080/health
```

**Local dev:**

```bash
curl http://localhost:8081/health
```

Expected response:

```json
{"status":"ok"}
```
