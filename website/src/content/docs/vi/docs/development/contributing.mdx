title: Đóng góp
description: Cài đặt CaberOS local và chạy các kiểm tra của dự án.
---

Chào mừng đóng góp. CaberOS được phát triển end-to-end: tính năng vượt qua gateway, harness, syscall, storage, hoặc frontend được triển khai như vertical slice.

## Cài đặt

Xem [Phát triển local](/vi/docs/development/local-development/) cho yêu cầu, cài đặt, và chạy dev server.

## Kiểm tra backend

```bash
cd backend
uv run pytest -v
uv run ruff check src/ tests/
uv run ruff format --check src/ tests/
```

## Kiểm tra frontend

```bash
cd frontend
npm ci
npm run lint
npm run build
npm run test
```

## Build desktop (chỉ macOS)

```bash
cd frontend
npm run desktop:build
```

Build đóng gói PyInstaller gateway và React frontend. Release build cần Tauri signing secrets cấu hình trong GitHub Actions.

## Build website

```bash
cd website
npm install
npm run build
```

## Hướng dẫn

- Triển khai tính năng end-to-end khi vượt qua gateway, harness, syscall, storage, hoặc frontend.
- Thêm behavioral test tại public seam.
- Giữ security-sensitive failure generic cho API client.
- Bao gồm lệnh kiểm tra liên quan trong pull request.
- Tuân theo code style và pattern hiện có — kiểm tra file lân cận trước khi giới thiệu abstraction mới.
