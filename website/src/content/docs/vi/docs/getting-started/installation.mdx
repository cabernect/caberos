CaberOS chạy trên macOS, Linux, và Windows (qua WSL2). Chọn tùy chọn phù hợp với nền tảng của bạn.

## Tùy chọn 1: Desktop app (dễ nhất, macOS Apple Silicon)

Desktop release hiện hỗ trợ **macOS 13 trở lên trên Apple Silicon**: M1, M2, M3, hoặc M4. App đi kèm FastAPI gateway và không cần Python, Node, hoặc `uv`.

1. Mở [bản phát hành mới nhất](https://github.com/cabernect/caberos/releases/latest).
2. Tải `CaberOS_<phiên bản>_arm64.dmg`.
3. Mở DMG và kéo **CaberOS** vào **Applications**.
4. Khởi động CaberOS từ Applications.

### Thông báo Gatekeeper

Bản phát hành được ad-hoc signed và không được Apple notarize. Nếu macOS báo ứng dụng không thể mở hoặc bị hỏng, trước tiên xác minh DMG từ bản phát hành chính thức, sau đó chạy:

```bash
xattr -dr com.apple.quarantine /Applications/CaberOS.app
```

Khởi động lại CaberOS sau khi xóa thuộc tính quarantine.

## Tùy chọn 2: Docker (mọi nền tảng)

Docker là cách dễ nhất để chạy CaberOS trên Linux, macOS, hoặc Windows (qua WSL2).

```bash
git clone https://github.com/cabernect/caberos.git
cd caberos
./scripts/docker.sh up
```

Mở `http://localhost:8080` và đăng nhập với `admin` / `admin`.

Xem [hướng dẫn triển khai Docker](/vi/docs/guides/docker/) cho cấu hình, lưu trữ dữ liệu, và cài đặt Postgres.

## Tùy chọn 3: Phát triển local

Cho development build trên macOS, Linux, hoặc WSL2:

```bash
git clone https://github.com/cabernect/caberos.git
cd caberos
./scripts/install.sh
./scripts/dev.sh
```

Mở `http://localhost:5173`. Xem [Phát triển local](/vi/docs/development/local-development/) cho yêu cầu và quy trình đầy đủ.

## Tóm tắt hỗ trợ nền tảng
