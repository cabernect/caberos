CaberOS chạy trên macOS, Windows, và Linux. Chọn tùy chọn phù hợp với nền tảng của bạn.

## Tùy chọn 1: Desktop app (dễ nhất)

App đi kèm FastAPI gateway và không cần Python, Node, hoặc `uv`. App phát hành cho **macOS 13 trở lên trên Apple Silicon** (M1–M4) và **Windows 10 trở lên trên x64**.

### macOS

1. Mở [bản phát hành mới nhất](https://github.com/cabernect/caberos/releases/latest).
2. Tải `CaberOS_<phiên bản>_arm64.dmg`.
3. Mở DMG và kéo **CaberOS** vào **Applications**.
4. Khởi động CaberOS từ Applications.

#### Thông báo Gatekeeper

Bản phát hành được ad-hoc signed và không được Apple notarize. Nếu macOS báo ứng dụng không thể mở hoặc bị hỏng, trước tiên xác minh DMG từ bản phát hành chính thức, sau đó mở **Terminal** và chạy:

```bash
xattr -dr com.apple.quarantine /Applications/CaberOS.app
```

Khởi động lại CaberOS sau khi xóa thuộc tính quarantine.

### Windows

1. Mở [bản phát hành mới nhất](https://github.com/cabernect/caberos/releases/latest).
2. Tải `CaberOS_<phiên bản>_x64-setup.exe`.
3. Chạy installer — cài cho user hiện tại, không cần quyền admin.
4. Khởi động CaberOS từ Start menu.

#### Thông báo SmartScreen

Installer chưa được ký bằng chứng chỉ phổ biến. Nếu Windows SmartScreen cảnh báo lần chạy đầu trong khi chữ ký tích lũy reputation, chọn **More info → Run anyway** sau khi xác minh file tải từ bản phát hành chính thức.

#### Shell sandbox trên Windows

Shell command chạy trong Microsoft Execution Containers (MXC) đi kèm installer — không cần Docker hay WSL, nhưng yêu cầu **Windows 11 24H2 (build 26100) trở lên** và setup elevated một lần: mở **Observability → Health** và bấm **Enable shell sandbox**. Trên build cũ hơn mọi thứ khác vẫn hoạt động; chỉ capability `terminal` tắt. MXC được báo là *experimental*, không phải security boundary đã xác minh — xem `docs/platform-support.md` cho ma trận đầy đủ.

## Tùy chọn 2: Docker (mọi nền tảng)

Docker là cách dễ nhất để chạy CaberOS trên Linux, macOS, hoặc Windows (qua WSL2).

```bash
git clone https://github.com/cabernect/caberos.git
cd caberos
./scripts/docker.sh up
```

Mở `http://localhost:8080` và đăng nhập với `admin` / `admin`.

Xem [hướng dẫn triển khai Docker](/vi/docs/guides/docker/) cho cấu hình, lưu trữ dữ liệu, và cài đặt Postgres.

## Tùy chọn 3: Phát triển local

Cho development build trên macOS, Linux, hoặc WSL2:

```bash
git clone https://github.com/cabernect/caberos.git
cd caberos
./scripts/install.sh
./scripts/dev.sh
```

Mở `http://localhost:5173`. Xem [Phát triển local](/vi/docs/development/local-development/) cho yêu cầu và quy trình đầy đủ.
