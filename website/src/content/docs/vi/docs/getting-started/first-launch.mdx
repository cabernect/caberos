CaberOS tạo thư mục dữ liệu local lần đầu gateway khởi động. Desktop shell chờ local health endpoint trước khi hiển thị dashboard.

## 1. Đăng nhập

Tài khoản operator ban đầu:

```text
username: admin
password: admin
```

Luồng onboarding sẽ yêu cầu thay credential mặc định ngay trong wizard — hãy làm việc đó trước khi tiếp tục. Bạn có thể đổi lại sau trong Settings.

## 2. Làm theo onboarding guide

Wizard lần chạy đầu dẫn qua các bước:

- **Welcome** — CaberOS là gì và những gì ở lại trên máy này.
- **Protect your workspace** — thay credential đăng nhập mặc định.
- **Get your machine ready** — kiểm tra readiness thật qua các probe health và dependency local, gồm managed browser và command sandbox; các runtime tùy chọn có thể cài hoặc bỏ qua.
- **Connect an AI** — thêm API key của model provider hoặc endpoint model local và kiểm tra kết nối.
- **Choose what agents may do** — posture permission mặc định.
- **Meet your agents** — xem lại các agent có sẵn.
- **Ready** — bạn đến trang **Today**, màn hình chính của operator hiển thị agent đã làm gì và đang cần bạn ở đâu.

Sau onboarding, Today đề xuất một tour ngắn ba bước qua các màn hình chính. Bạn có thể chạy lại bất cứ lúc nào từ **Settings → General → Guidance → Replay tour**.

## 3. Gửi message đầu tiên

Mở agent **Caber** và yêu cầu agent kiểm tra workspace. Một run thành công sẽ hiển thị:

- user message;
- model response streaming;
- thinking hoặc tool activity;
- approval prompt khi cần;
- run hoàn tất trong trace view.

## 4. Kiểm tra health

Health view của dashboard báo cáo database, provider, agent, run đang hoạt động, MCP server và channel.

Bạn cũng có thể kiểm tra gateway trực tiếp:

**Desktop app:**

```bash
curl http://127.0.0.1:51718/health
```

**Docker:**

```bash
curl http://localhost:8080/health
```

**Local dev:**

```bash
curl http://localhost:8081/health
```

Kết quả mong đợi:

```json
{"status":"ok"}
```
