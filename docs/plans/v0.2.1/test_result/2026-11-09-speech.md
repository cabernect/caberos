Scope: operator speech — dictation STT, read-aloud TTS, adapter support
matrix, Tauri mic bridge. Commits `d4d00b1`…`e19bce1` on `feat/v0.2.1`
(renderer → service/endpoints → six adapter contracts → dictation/speaker

## Verified (live, local machine)

- **OpenRouter dedicated TTS** — `heygen/heygen-voice-1-turbo:free` +
  configured voice `nadine`: mp3 request → HTTP 400 → adapter parsed the
  provider error (`only supports response_format "pcm"`) → retried once
  → `audio/pcm;rate=44100;channels=1` → wrapped to WAV, 105 KB playable.
- **OpenRouter dedicated STT** — `openai/whisper-large-v3-turbo` +
  1 s generated WAV → transcript `'.'` (correct silence behaviour on a
  sine tone) + `audio_seconds: 1` from `verbose_json`.
- **Tauri mic bridge** — `NSMicrophoneUsageDescription` verified embedded
  in the dev binary's `__info_plist`; the macOS TCC prompt appeared on
  first mic click in the running `tauri dev` shell (operator-confirmed).
- `X-Speech-Reused` cache path exercised in tests: second identical
  synthesis → `synthesis_replay` receipt, zero dispatch.

## Verified earlier in-session

- `POST /api/speech/status|transcribe|synthesize` contracts, rate limits,
  15 MiB / MIME / 10k-char bounds, pre-dispatch cancellation → zero calls,
  zero receipt; `model_calls` rows carry `kind="speech"`, typed units
  (`audio_bytes`, `audio_seconds`, `text_chars`, `characters_reported`),

## Not verified / open

- **Scripted browser QA** — the mic → transcript → caret-insertion and
  speaker → spinner → playback click-throughs were exercised manually
  during development; no recorded Playwright pass. Mobile untested.
- **ElevenLabs** — provider plumbing verified end-to-end (binding,
  key custody, request reaching the API); the account's free tier
  rejects library/premade voices at the paywall (HTTP 402
  `paid_plan_required`), so actual audio synthesis is unverified
  until a self-created voice or paid plan exists.
- **Groq / local OpenAI-compatible servers** (Speaches/LocalAI) —
  fixture-verified; the `_audio_*` helper path is shared with the
  live-verified OpenRouter dedicated route. No live local server
  was tested.
- **Provider matrix note (post-W10):** Deepgram and Gradium were
  removed in `24def7c` and Gemini added — STT `generateContent`
  inlineData and TTS AUDIO-modality → PCM→WAV. Both Gemini paths
  were subsequently exercised live by the operator (`gemini-2.5-flash`
  STT, `gemini-2.5-flash-preview-tts` TTS) — Gemini joins OpenRouter
  in the live-verified column.
- **Speech cost** — estimation was implemented then deliberately removed
  (`e19bce1`): a frozen source-level rate table doesn't match the
  catalog + `ModelOffering.overrides` convention. Receipts keep honest
  billable units only; `cost` stays unknown.
- **OpenRouter routing** keys off model-slug substrings
  (`tts|voice|speak` → `/audio/speech`, `whisper|stt|transcri` →
  `/audio/transcriptions`); a catalog-modality-driven router is a
  possible future improvement.
- **Tauri CSP `media-src 'self' blob:`** added for bundled playback;
  verified in code, not yet exercised in a packaged build.
- `gpt-4o-mini-tts` and token-billed audio models have no char/minute
  rate — would stay unknown even under a future rate store.
